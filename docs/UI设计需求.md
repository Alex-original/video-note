# 视频转笔记 · UI 设计需求文档

## 一、项目概述

这是一个将 B 站视频转换为总结文档的工具：用户粘贴视频链接，系统自动获取字幕（无字幕则转写音频），由大模型分块摘要并汇总，生成结构化的 Markdown 总结笔记。

**核心模块：**

1. 登录模块：手机号 + 短信验证码登录，登录后进入转换页面；
2. 转换功能：输入视频链接，点击开始转换，弹出二次确认弹窗（选分 P、预估费用），确认后加入任务列表并开始转换；
3. 任务进度表：实时展示任务状态、进度、耗时与成本，完成后可下载笔记、展开预览；
4. 充值模块：按 0.8 元 / 15 分钟计费，转换前预检余额，生成支付订单、到账后更新余额；
5. 退出登录模块：清除会话，返回登录页。

## 二、目标用户与使用场景

- **目标用户**：B 站重度用户、学生、财经/知识内容学习者、自媒体/内容从业者。
- **使用习惯**：以**移动端为主**（手机浏览器访问），习惯 B 站 App 的交互直觉。
- **核心场景**：看到一条干货视频 → 贴链接 → 拿结构化笔记 → 收藏/复习/转发。
- **核心诉求**：省时间（不手动记笔记）、内容结构化、可下载、可多分 P 处理。

## 三、核心用户流程

1. **登录**：输入手机号 → 点「发送验证码」→ 收码输入 → 登录进入主界面。
2. **转换**：粘贴链接 → 点「开始转换」→ 弹窗选分 P + 看费用 → 确认 → 任务进入列表后台转换。
3. **查看/下载**：任务表实时刷新 → 完成后下载笔记 / 展开预览。
4. **充值**：点「充值」→ 输入金额 → 生成订单 → 支付 → 余额更新。

## 四、页面清单与元素说明

| 页面 | 关键元素 |
|---|---|
| **登录页** | 产品名/标语、手机号输入框、验证码输入框 + 「发送验证码」按钮、登录按钮、协议/隐私政策入口 |
| **转换页（主界面）** | 顶部：登录手机号 + 余额 + 「充值」+「退出登录」；中部：视频链接输入框 + 「开始转换」按钮、输出标签下拉；下方：任务进度表 |
| **二次确认弹窗** | 视频标题、分 P 多选列表（含每 P 时长）、本次费用、当前余额、「确认转换」/「取消」 |
| **任务进度表** | 余额展示、任务卡片列表：状态徽章、标题、提交时间、成本、进度消息、停止/下载按钮、展开预览 |
| **充值弹窗** | 计费规则说明（含费用示例）、金额输入、生成订单按钮、订单信息、支付确认 |
| **输出标签管理** | 折叠面板：标签名、输出格式提示词、保存/新建/删除 |

## 五、设计风格与视觉方向

- **整体感觉**：简洁、清爽、**可信赖**（涉及付费，需降低用户顾虑）、移动优先。
- **配色**：浅色为主，主色建议用沉稳的**靛蓝/蓝紫**系（传递「AI 工具 + 专业」感），白色卡片 + 柔和阴影。
- **状态色**（已有约定，可沿用）：
  - 转换中 `#d97706`（琥珀）、已完成 `#16a34a`（绿）、失败 `#dc2626`（红）、已停止 `#6b7280`（灰）。
- **层级**：标题清晰、正文留白充足、重要动作（开始转换/确认）用高对比主按钮。
- **组件**：圆角卡片、状态徽章（彩点 + 文字）、悬浮弹窗（遮罩 + 居中，移动端占屏比高）、列表式任务流。

## 六、关键交互状态

- **加载中**：转换各阶段（解析/字幕/下载/转写/摘要/汇总）有进度提示，避免「卡住」感。
- **空状态**：无任务时显示友好提示（如「暂无转换任务」）。
- **错误态**：余额不足、链接解析失败、验证码错误等，用明确可读的报错提示，不打断流程。
- **成功态**：转换完成/充值成功有明确反馈。

## 七、移动端适配

- 单列布局，按钮和输入框触控友好（足够大的点击区域）。
- 弹窗在小屏上占满宽度、内容超高可滚动。
- 关键操作（开始转换、确认、下载）拇指易达。

## 八、技术约束（供 AI 参考，不影响 UI 稿）

- 前端为 Gradio（Python 构建），组件能力偏「表单 + 列表 + 弹窗」，无复杂自定义动画。
- 弹窗通过 CSS 实现悬浮遮罩（`position: fixed`）。
- 任务表每 5 秒轮询刷新。
