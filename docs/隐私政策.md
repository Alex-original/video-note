# 隐私政策

更新日期：2026-08-22

欢迎使用「视频转笔记」服务（以下简称"本服务"）。我们深知个人信息对您的重要性，将按照《中华人民共和国个人信息保护法》等法律法规的要求，采取相应安全保护措施，尽力保护您的个人信息安全。请您在使用本服务前，仔细阅读并充分理解本政策。

## 一、我们收集的信息

1. **账号信息**：手机号（用于注册与登录）；内测期使用的邀请码、正式期的短信验证码。
2. **计费信息**：账户余额、充值记录、消费记录。
3. **任务与内容信息**：您提交的视频链接、选中的分P与输出标签、生成的笔记内容、转写文本。
4. **日志信息**：访问时间、操作记录等，用于保障服务安全与排查故障。

## 二、我们如何使用信息

- 完成身份识别与登录；
- 提供视频转笔记服务并展示任务进度；
- 进行计费与余额管理；
- 保障服务安全、改进服务质量。

## 三、信息的存储与保护

我们采用行业通用的安全措施保护您的信息，并将信息存储于境内服务器。除法律法规另有规定外，我们仅在实现本政策所述目的所必需的期限内保留您的个人信息。

## 四、第三方共享

为实现服务，我们可能与以下第三方共享必要信息：

- **文本摘要**：DeepSeek（处理转录文本以生成笔记）；
- **语音转写**：阿里云百炼 DashScope（无字幕时转写音频）；
- **短信服务**（正式期）：短信服务商（发送验证码）；
- **支付服务**（正式期）：微信支付、支付宝（完成充值）。

上述第三方仅能基于我们的委托处理相应信息，并承担保密义务。

## 五、您的权利

您可以查询、更正您的个人信息，并可要求删除您的账号及关联数据（包括笔记、任务记录等）。您可通过本政策第八条所述方式联系我们行使上述权利。

## 六、未成年人保护

本服务面向具备完全民事行为能力的用户。如您为未成年人，请在监护人指导下使用。

## 七、政策更新

本政策可能适时更新，更新后我们会在显著位置提示。重大变更将以适当方式另行通知。

## 八、联系方式

如对本政策有任何疑问、意见或建议，请通过 [联系方式占位] 与我们联系。
