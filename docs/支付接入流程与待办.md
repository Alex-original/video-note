# 支付接入流程与待办

> 记录日期：2026-08-24（更新：2026-08-27）
> 状态：**个体户已下发，进入税务登记 + 商户号申请阶段**

从「个体工商户注册」到「正式接入支付宝/微信支付」的完整链路。

## 完整流程

### 阶段 1：注册个体工商户（✅ 已完成 2026-08-27）
- 电子营业执照已下发，与纸质同等效力。

### 阶段 2：领证后的行政事项（领证后立刻做）
1. **税务登记**（⚠️ 30 天内必须）：浙江省电子税务局 → 税务信息确认 + 税种核定，零收入也要按期申报。
2. **刻章**：基础公章免费。
3. **确定结算银行卡**：商户号收款打款账户。

### 阶段 3：申请支付商户号（微信 + 支付宝，可并行）

| | 支付宝 | 微信支付 |
|---|---|---|
| 入口 | 支付宝商家平台（当面付 / 电脑网站支付）| 微信支付商户平台（Native / JSAPI）|
| 材料 | 营业执照 + 法人身份证 + 结算银行卡 | 同左 |
| 审核 | 3~7 天 | 3~7 天 |

- 申请「标准商户号」（不是个人码/小微），费率 0.6%、无额度限制、能做自动扣款回调。

### 阶段 4：拿到商户号后配置密钥
- **支付宝**：AppID + 应用私钥 + 支付宝公钥。
- **微信支付**：商户号 mchid + API v3 密钥 + 商户证书。
- 在支付平台后台配好**回调地址**（公网 URL）。

### 阶段 5：代码接入（技术侧，已搭好 80%）

```
用户充值 → 生成订单 → 调支付接口拿二维码 → 扫码付款
        → 支付平台回调 → 验签（防伪造）→ 幂等充值到账
```
